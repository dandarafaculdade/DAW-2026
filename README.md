# Cardápio Digital

Projeto desenvolvido para a disciplina de **Desenvolvimento de Aplicações Web**, com o objetivo de praticar a estruturação de páginas utilizando **HTML**, **CSS** e **JavaScript**.

## Objetivo

A aplicação representa um cardápio digital de uma lanchonete, contendo categorias de produtos, cards com informações dos itens e uma área destinada ao carrinho de compras.

Neste estágio do projeto, algumas funcionalidades possuem caráter demonstrativo e poderão ser incrementadas durante o desenvolvimento.

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Google Fonts

## Estrutura do projeto

```text
/
├── index.html
├── assets/
│   ├── css/
│   │   └── estilo.css
│   ├── img/
│   │   └── arquivos de imagens do projeto
│   └── js/
│       └── script.js
└── README.md
```

## Funcionalidades atuais

* Exibição dos produtos do cardápio;
* Organização dos produtos em categorias;
* Layout responsivo para diferentes tamanhos de tela;
* Destaque visual da categoria selecionada;
* Interação básica utilizando JavaScript;
* Estrutura inicial da área de carrinho.

## Organização do código

O projeto procura manter uma separação simples de responsabilidades:

* **HTML:** estrutura e conteúdo da página;
* **CSS:** estilização e responsividade;
* **JavaScript:** comportamentos e interações da interface.

O CSS também foi separado por seções, como cabeçalho, navegação, conteúdo principal, rodapé e responsividade, buscando facilitar a leitura e a manutenção do código.

## Boas práticas adotadas

Durante o desenvolvimento, buscou-se utilizar:

* HTML semântico;
* nomes de classes relacionados aos elementos da interface;
* organização dos arquivos por finalidade;
* indentação consistente;
* variáveis CSS para cores reutilizadas;
* media queries para responsividade;
* textos alternativos em imagens;
* separação entre estrutura, apresentação e comportamento.

## Execução

Para visualizar o projeto, basta abrir o arquivo:

```text
index.html
```

em um navegador.

Também é possível utilizar uma extensão como **Live Server** durante o desenvolvimento.
